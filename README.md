# 🤖 Telegram AI Chatbot (Google Gemini)

Асинхронный Telegram-бот на **Python 3.13** с использованием фреймворка **`aiogram 3`** и нейросети **Google Gemini 3.5 Flash-Lite**.

---

## ✨ Возможности
* 🧠 **Искусственный Интеллект**: Умные ответы на любые вопросы с сохранением контекста и памяти диалога.
* ⚡ **Сверхбыстрый отклик**: Асинхронная архитектура и статус «печатает...».
* 🔘 **Клавиатуры**: Reply-кнопки меню и Inline-кнопки настроек.
* 🧹 **Сброс контекста**: Очистка памяти диалога в 1 клик.
* 🌐 **Поддержка 24/7**: Встроенный сервер активности для облака Render.com / VPS.

---

## 📁 Структура проекта

```text
telegram-chatbots/
│
├── handlers/
│   ├── __init__.py
│   ├── keyboards.py        # Клавиатуры (Reply и Inline)
│   └── user.py             # Обработчики команд и сообщений
│
├── .env.example            # Шаблон конфигурации
├── .gitignore
├── config.py               # Загрузка настроек
├── main.py                 # Точка входа (запуск бота)
├── ai_service.py           # Интеграция с Google Gemini
├── server.py               # Фоновый веб-сервер для поддержки 24/7
├── render.yaml             # Конфигурация для деплоя на Render
├── README.md
└── requirements.txt
```

---

## 🚀 Запуск локально

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Запуск бота
python main.py
```
