# 🤖 Telegram Finance & AI Assistant Bot (Render 24/7)

Многофункциональный Telegram-бот на Python (`aiogram 3.x` + `SQLite` + `Google Gemini 3.6 Flash`), работающий в облаке Render в режиме 24/7. 

Бот объединяет персонального финансового AI-консультанта, автоматический парсер банковских выписок с расчётом динамики, диалогового ассистента и систему управления новостями для ACAT.KZ.

---

## 🌟 Ключевые возможности

### 1. 💰 Персональный финансовый учёт и AI-аналитика
- **📁 Импорт и парсинг банковских выписок (PDF)**:
  - Отправьте боту PDF-выписку из мобильного банка (*Home Credit*, *Kaspi*, *Forte* и др.).
  - Бот автоматически распознает транзакции, распределит их по категориям и внесёт в историю.
- **📈 Анализ динамики трат и выявление трендов (`/trends`)**:
  - Сравнение периодов (текущий vs предыдущий месяц / неделя).
  - Выявление **всплесков трат** (например: `⚠️ Доставка еды выросла на +34%`).
  - Подсчёт **сэкономленных средств** (например: `🎉 В ресторанах сэкономлено 25 000 ₸`).
  - Персональные AI-рекомендации по оптимизации расходов.
- **✍️ Мгновенный ввод расходов**:
  - **Текст**: `Обед 2600`, `Бензин 8000 в Qazaq Oil`, `Wolt 5400`, `Zara 25000` — Gemini мгновенно понимает сумму, категорию и комментарий.
  - **🎙 Голосовые сообщения**: отправьте аудио *(«Пообедал в ресторане на 3500 тенге»)* — бот расшифрует речь и запишет трату.
  - **🧾 Фото чеков**: распознавание чеков и позиций с фото.
- **🚨 Контроль лимитов и «Анти-слив» (`/limits`)**:
  - Предупреждения при приближении к 80% и превышении месячного лимита на рестораны и доставки.
  - Быстрая настройка: `Лимит Рестораны 60000`.
- **📊 Наглядные графики (`/stats`)**:
  - Построение круговых диаграмм структуры расходов прямо в чат Telegram (`matplotlib`).

## 🛠 Технологический стек
- **Язык**: Python 3.13
- **Telegram Framework**: `aiogram 3.x` (Long Polling + Web Healthcheck)
- **AI Engine**: `Google Gemini 3.6 Flash` (`google-genai`)
- **База данных**: `SQLite3`
- **PDF & Data Parsing**: `pypdf`, `openpyxl`
- **Визуализация**: `matplotlib`
- **Хостинг**: `Render.com` (Web Service с фоновым сервером для работы 24/7)

## 🚀 Запуск и деплой

### Локальный запуск:
```bash
git clone git@github.com:deniskakan8-arch/telegram-chatbots.git
cd telegram-chatbots
pip install -r requirements.txt
python main.py
```

### Деплой на Render (24/7):
Проект настроен на автоматический деплой через файл `render.yaml`. При каждом пуше в ветку `main` Render автоматически пересобирает и перезапускает бота.

В Environment Variables на Render должны быть указаны:
- `TELEGRAM_BOT_TOKEN`
- `GEMINI_API_KEY`
